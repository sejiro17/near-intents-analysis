# NEAR Intents: Adoption, Activity and Economic Value

## Research Question

Does NEAR Intents show sustained usage, and how does that activity contribute economic value to NEAR?

## Project Status

Preparation and data validation. No investment conclusions have been drawn.

## Planned Analysis

- Usage trends and returning participants.
- Concentration of activity across accounts.
- Fees and their relationship to NEAR’s economic value.

The final scope will depend on data availability and validation.

## Tools and Data

- SQL and Google BigQuery
- Python
- VS Code
- NEAR public blockchain dataset:
  `bigquery-public-data.crypto_near_mainnet_us`

- `sql/`: Queries for data checks and analysis.
